   详细报告: Free Claude Code (FCC) 是一个开源的本地代理工具，它把自己伪装成 AI 提供商的 API 端点，让各种编码代理（Claude Code、Codex 等）以为在跟 Anthropic 或 OpenAI 对话，实际上它把请求转发到任意你配置的模型提供商。这么做的好处是，你不需要为每个代理单独搞一套 API key，而且可以用上很多提供商的免费配额。

核心功能包括：

1. **统一模型路由**：FCC 内置 49 家提供商的接入配置，从 NVIDIA NIM、OpenRouter、Groq 到 OpenAI、xAI、Google Gemini，甚至本地 Ollama、LM Studio。你在一个 Admin UI 里填入各家的 API key，然后统一选择模型。Admin UI 支持搜索和校验模型，还能为不同的 Claude 模型层级（Opus、Sonnet 等）单独指定不同的底层模型。

2. **故障转移**：这是最贴心的功能。当你当前使用的模型因为配额、网络等原因请求失败时，FCC 会自动按你配置的备用模型顺序重试，整个过程对用户透明，不用手动重启会话。对于重度用户来说，这就是'打工人神器'，不用因为一个提供商挂了就卡死。

3. **Token 省钱优化**：它集成了 RTK，可以把那些常见的终端输出（比如编译日志、测试输出）压缩掉，最高减少 90% 的 token 消耗。同时还有 5 项内置优化，避免在配额探测、命令前缀、标题、建议和文件路径这些场景浪费 token，直接省下真金白银。

4. **多客户端兼容**：支持 Claude Code、Codex、Pi、OpenCode、Cline、Hermes、DeepSeek Harness、Grok Build、Muse Code 这 9 种代理。你可以用同一个模型库跑不同的代理，而且在 VS Code、JetBrains 里也能接上。

5. **多端交互**：除了本地命令行，还提供 Discord 和 Telegram 机器人，能在手机上远程启动任务。另外还支持语音消息，用本地 Whisper 或 NVIDIA NIM 把语音转成文字，然后喂给 agent。

6. **安全与控制**：Admin UI 里可以开启代理认证，防止别人偷用你的模型配额。针对不同的模型 tier（Fable/Opus/Sonnet/Haiku）可以做路由覆盖，还能控制推理深度（Reasoning），从 Off 到 Max 自由选择。

技术上，它主要通过 Python 实现，安装脚本支持 macOS/Linux (bash) 和 Windows (PowerShell)。本地代理默认监听 8082 端口（示例中 Claude Code 通过 ANTHROPIC_BASE_URL 指向它），并支持 OpenAI 兼容格式。语音功能依赖 PyTorch 和 Whisper 或 NVIDIA NIM 的 API。

   详细报告: book-to-skill 是一个极具创意的开源项目，它解决了开发者“买了技术书却记不住内容”的痛点。传统阅读方式下，你读完一本书，几个月后可能连章节标题都忘了，而翻 PDF 搜索又只能得到页码列表，问 AI 助手它要么胡说八道要么说没有内容。这个项目的核心思路是：把整本书（或任何结构化文本）转化为一个符合 Agent Skills 标准的技能目录，让 AI 助手在需要时按需加载对应章节，从而用最少的 token 获得精确答案。

工作流程分三步：首先你通过命令 `/book-to-skill your-book.pdf` 指向一个文件、文件夹或 glob 模式；接着工具会用一个确定性的 Python 提取器将文档转换为干净的文本和元数据，再通过一个由 SKILL.md 驱动的生成器将文本结构化为框架、决策规则、反例、每章独立文件等；最后，你的 AI 助手（如 Copilot CLI、Amp、Claude Code）可以通过 `/your-book-slug 主题` 这样的命令，在需要时加载对应章节文件，直接基于真实内容回答，避免幻觉。

生成的结构包含 `SKILL.md`（核心心智模型 + 章节索引）、`chapters/`（每章一个文件，按需加载）、`glossary.md`（术语表）、`patterns.md`（技术/算法/设计模式）、`cheatsheet.md`（快速参考表）。这种设计的亮点在于全部采用 Markdown 格式，且每个文件都很小（章节约 1000 tokens），极大降低了上下文占用。据项目文档，相比直接把整本书扔进上下文，它可节省 24 到 51 倍的 token，因为 AI 不需要反复导航目录、回溯重读。

项目还支持多种文档格式：PDF 会根据书籍类型自动选择不同引擎（技术类用 docling 保留代码表格，文本类用 pdftotext）；EPUB 用 ebooklib 和 BeautifulSoup；还有其他格式如 DOCX、HTML、RTF、MOBI 等。所有处理都在本地完成，保护隐私，且不附带任何书籍内容，仅作为转换工具，符合合理使用原则。

除了书籍，它还能处理内部文档、品牌规范、研究论文、规范和标准等，凡是需要反复查阅的资料都能变成可查询的技能。安装非常便捷，可通过 `npx skills add` 一键添加到各种宿主环境，或者手动克隆到对应 skills 目录。整体来说，这个项目是 AI 时代的“知识蒸馏器”，让文档的价值真正融入工作流。

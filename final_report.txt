   详细报告: Voice-Pro 是一个基于 Web 的 AI 语音处理套件，目标是让创作者、研究人员和多语言专业人士能够轻松处理音视频内容。它就像一把瑞士军刀，把许多原本需要分开使用的工具整合到了一个界面里。

从功能上看，它主要包含四大模块：
1. **Dubbing Studio（配音工作室）**：这是核心功能。你可以粘贴一个 YouTube 链接，它会用 yt-dlp 下载视频并提取音频，然后用 Demucs 进行人声分离（比如去掉背景音乐），接着用 Whisper 系列模型进行语音识别生成字幕，再通过 Deep-Translator 翻译成目标语言，最后用 TTS 引擎生成配音。整个过程一气呵成，输出的音频可以是 WAV、FLAC、MP3 格式。
2. **Whisper Caption（字幕生成）**：专门用于生成高质量字幕，支持 90+ 语言，可以嵌入视频显示，还有单词级高亮和降噪选项，非常适合做视频字幕。
3. **Translate（翻译）**：支持 100+ 语言，不仅可以直接翻译文本，还能翻译字幕文件（ASS、SSA、SRT 等），甚至支持实时语音识别和翻译，相当于一个实时翻译机。
4. **Speech Generation（语音合成）**：提供了多种 TTS 引擎，包括 Edge-TTS（免费、多语言多声音）、F5-TTS、CosyVoice 和 kokoro。其中 F5-TTS 和 CosyVoice 支持零样本声音克隆，你可以上传一段参考音频，就能生成同样的声音，甚至可以用名人声音做播客（项目内置了不少参考声音样本，比如 Elon Musk、Joe Rogan 等，但需注意版权和伦理问题）。

技术栈方面，项目使用 Python 3.12，基于 Gradio 6 构建 WebUI，底层用 PyTorch 2.8.0 和 CUDA 加速。语音识别用的是 OpenAI 的 Whisper 及其加速版 Faster-Whisper 和带时间戳的 Whisper-Timestamped。TTS 方面集成了 Edge-TTS、F5-TTS、E2-TTS、CosyVoice 和 kokoro。翻译使用 Deep-Translator（免费额度的谷歌翻译接口），也支持 Azure Translator（需要自己的密钥）。音频分离使用 Demucs。此外还用了 yt-dlp 下载视频，用 uv 管理依赖，大大简化了安装流程。

值得一提的是，项目的安装体验很友好：不需要预先安装 CUDA Toolkit 和 Visual Studio Build Tools，因为 PyTorch 已经自带 CUDA 运行时；也不需要管理员权限，start.bat 会自动下载便携版 FFmpeg。WebUI 中错误提示会一直显示红色 toast，直到你手动关闭，避免漏掉重要信息。

不过，文档也提到了一些限制：官方主要验证了 Windows + NVIDIA GPU 的环境，Mac 和 Linux 虽然可能支持，但未经过充分测试。首次运行需要下载约 10GB 的模型，比较耗时。另外，项目目前因为开发团队忙于另一个项目（WeConnect）而暂停了积极开发，但代码已完全开源，所以任何人都可以继续维护和修改。

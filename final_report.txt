   详细报告: oMLX 是一个面向 macOS 的本地 LLM 推理服务器，核心目标是在 Apple Silicon（M1/M2/M3/M4）上提供高效、灵活、可控制的大模型服务。它解决了现有 LLM 服务器在“便利性”和“控制力”之间二选一的痛点，让用户既能像使用 ChatGPT 一样方便，又能像 vLLM 那样精细管理缓存和模型调度。

项目主要包含以下几个核心亮点：

1. **分级 KV 缓存（Tiered KV Cache）**：采用 vLLM 启发的块级缓存管理，包含热层（内存）和冷层（SSD）。当上下文变化时，旧上下文仍能被缓存并复用，甚至服务器重启后也能从 SSD 恢复。这对 Claude Code 等编码工具至关重要，使得本地 LLM 在真实编码场景中变得实用。

2. **连续批处理（Continuous Batching）**：基于 mlx-lm 的 BatchGenerator 实现，支持并发请求的高效处理，提升 GPU 利用率。

3. **多模型 Serving**：支持同时加载 LLM、VLM、Embedding 和 Reranker 模型，并自动按类型识别。具备 LRU 自动淘汰、手动加载/卸载、模型固定（Pin）、每模型 TTL 超时和总内存限制，有效防止 OOM。

4. **macOS 菜单栏 App**：原生 Swift/SwiftUI 编写（非 Electron），提供一键启动/停止、状态监控、崩溃自动重启和自动更新。菜单栏集成统计信息，无需命令操作。

5. **API 兼容性**：完全兼容 OpenAI 和 Anthropic API，提供 /v1/chat/completions、/v1/completions、/v1/messages、/v1/embeddings、/v1/rerank 等接口，支持流式、视觉输入和工具调用。可作为 Drop-in replacement。

6. **管理后台**：Web UI 提供模型下载（HuggingFace）、实时监控、聊天、基准测试和每模型设置，支持多语言（中、英、日、韩等），所有 CDN 依赖内嵌，可完全离线使用。

7. **多 Mac 分布式推理（实验性）**：支持通过 MLX pipeline ranks 将模型拆分到不同内存大小的 Mac 上，使用 Ring 或 Thunderbolt RDMA/JACCL 通信，提供实时分片/性能地图。

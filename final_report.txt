工作流程分五步：第一步是图构建（Graph Building），包括种子提取、个体/集体记忆注入和 GraphRAG 构建，把输入信息结构化，并建立知识图谱。第二步是环境设置（Environment Setup），进行实体关系提取、人设生成和智能体配置注入，为模拟准备角色。第三步是模拟（Simulation），采用双平台并行模拟引擎，自动解析预测需求，并动态更新时态记忆。第四步是报告生成（Report Generation），ReportAgent 带着丰富的工具与模拟后的环境深度交互，生成详细的预测报告。第五步是深度交互（Deep Interaction），你可以与模拟世界中的任意智能体聊天，或与 ReportAgent 进一步探讨。

技术上，MiroFish 采用前后端分离架构。后端使用 Python（≥3.11, ≤3.12），依赖管理使用 uv，提供 LLM API 接口（兼容 OpenAI SDK 格式），推荐使用阿里云百炼平台的 qwen-plus 模型。前端基于 Node.js 18+，使用 npm 管理依赖。数据存储和记忆服务用 Zep Cloud，负责长期记忆管理。模拟引擎核心是 OASIS（Open Agent Social Interaction Simulations），这是 CAMEL-AI 团队的开源项目，MiroFish 站在巨人的肩膀上，实现了群体智能的涌现。环境变量中需要配置 LLM 和 Zep 的 API 密钥，部署方式支持源码部署和 Docker 一键启动，对开发者非常友好。

   项目简介: Soup 是一个一键微调 LLM 的命令行工具，通过层流式技术让 8B 模型在 4GB 笔记本 GPU 上也能微调，无需 SSH 和复杂配置。
   亮点: 一键微调：soup init + soup train，零 SSH 零配置地狱; 层流式技术（Layer Streaming）：8B 模型在 4GB 笔记本 GPU 上微调，实测 119.6 tok/s，3.32GB 峰值显存，bit-exact 与普通训练一致; 支持多种训练任务：SFT、DPO、GRPO、PPO、KTO、ORPO、SimPO、IPO 等; 自带评估门控：soup ship 自动判断模型是否变好，防止回归; 数据工程工具丰富：自动检测多种数据格式，支持合成数据与质量评分
   详细报告: Soup 是一个专为 LLM 微调而生的命令行工具，目标是把微调过程中的基础设施痛苦降到最低。通常微调一个模型需要配置 GPU 环境、处理 SSH 连接、手动设置轮次/学习率/量化等参数，而 Soup 通过一个简单的 YAML 配置文件即可完成所有操作。核心亮点是"层流式"（Layer Streaming）技术：传统 QLoRA 微调时需要将完整的基础模型加载进显存，而 Soup 会将冻结的基础模型按层流式传输到 GPU，只让可训练的适配器驻留显存，从而在 4GB 显存的笔记本 GPU（如 RTX 3050）上就能微调 8B 参数模型。根据文档，实测 Llama-3.1-8B-Instruct + NF4 量化可达到 119.6 tok/s 的吞吐，峰值显存仅 3.32GB，且与普通占用显存的训练方式 bit-exact 一致（即结果完全相同）。该技术还支持 DPO/ORPO/SimPO/KTO 等偏好对齐损失，且不需要额外参考模型，而是复用流式基础模型并关闭适配器，避免了双倍显存开销。Soup 还内置了丰富的评估与发布门控：`soup ship` 可以自动运行多个离线测试套件（如 MCQ、数学、工具调用、JSON 有效性、安全/拒绝），根据分数判定是否应该发布模型，有效防止"调优后反而变差"的情况。数据工程方面，支持 Alpaca、ShareGPT、ChatML、偏好对等多种格式，自动检测 JSONL/JSON/CSV/Parquet/TXT，并提供数据分割、合成数据生成、质量评分等功能。此外，Soup 支持导出 GGUF、ONNX、TensorRT 等格式，方便部署到 Ollama 或 llama.cpp，同时提供 OpenAI 兼容的 API 服务。项目还包含 100+ 现成模型配方（recipes），覆盖各种主流模型，并支持 MLX、Unsloth 等后端。从版本历史看，项目迭代活跃，文档非常详细（docs/ 目录包含训练方法、效率优化、数据工程、评估、合规等大量指南），并附有基准测试和论文（Zenodo）证明其技术有效性。需要注意的是，层流式功能仍标注为 BETA，且仅支持 Python 3.10-3.12，另外部分高级功能（如 GRPO/PPO）暂不支持层流式。总体而言，Soup 是一个极具创新性和实用性的工具，尤其适合个人开发者或小团队在消费级 GPU 上微调大模型。

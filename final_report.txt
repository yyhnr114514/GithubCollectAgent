   项目简介: Spec Kit 是一个开源工具包，它让 AI 编码代理先定义规格（Spec）再写代码，通过可执行的规格驱动开发（SDD）流程，帮助你“想清楚再动手”，告别一锅乱炖的 AI 编程。

   详细报告: Spec Kit 是一个由 GitHub 发布的开源工具包，核心目标是解决传统 AI 编码中“一窝蜂”式生成代码导致质量不可控的问题。它引入了“规格驱动开发”的理念：先定义“做什么”（规格），再决定“怎么做”（技术方案），最后才生成代码。整个流程通过 `specify` CLI 和一系列 `/speckit.*` 斜杠命令（或 agent skills）与 AI 编码代理无缝集成。

具体来说，你只需要执行几步：1) 使用 `specify init` 初始化项目；2) 通过 `/speckit.constitution` 为项目制定“宪法”（即开发原则和治理规则）；3) 用 `/speckit.specify` 用自然语言描述需求（聚焦“what”和“why”，不纠结技术栈）；4) 用 `/speckit.plan` 输入你偏好的技术栈和架构；5) 用 `/speckit.tasks` 将计划拆解为可执行的任务；6) 用 `/speckit.implement` 让 AI 按任务逐个实现。此外，还有 `converge`（对照规格/计划检查差距并补充任务）、`clarify`（澄清模糊需求）、`analyze`（交叉一致性分析）、`checklist`（生成质量检查清单）等可选命令，全程为你的项目保驾护航。

Spec Kit 的强大之处还在于它的可扩展性：它提供了三种定制层级——扩展（Extensions）可以增加全新功能（比如 Jira 集成、代码审查、V-Model 追踪）；预设（Presets）可以改变现有流程的呈现方式（比如调整规格模板以符合法规要求、切换术语、改变任务顺序）；而捆绑包（Bundles）则把多个扩展和预设打包成一个角色化的配置，一条命令就能给产品经理、业务分析师、安全研究员等不同角色配好全套流程。这些组件按优先级堆叠，并支持项目局部覆盖，意味着你可以让团队里每个人用不同的“姿势”享受 Spec Kit。

该工具支持 30+ 种 AI 编码代理，包括 Claude Code、GitHub Copilot、Codex CLI 等，既能运行在纯命令行环境，也能融入 IDE 工作流。它可以在三种开发阶段中使用：0-to-1 全新建项目（从零生成生产级应用）、创造性探索（同时用不同技术栈并行尝试多种方案）、迭代增强（给老项目加功能或现代化改造）。在技术层面，Spec Kit 使用 Python 编写 CLI，依赖 uv 或 pipx 安装，通过模板和提示词文件操作 AI 代理，并且所有自定义组件都以模板形式存放在项目的 `.specify/` 目录下，运行时按优先级解析。安装时会将命令文件写入 agent 的配置目录（如 `.claude/commands/`），如果是 skills 模式则安装为 skill。对于企业用户，它还支持离线 bundle 验证与安装，确保合规和可追溯。

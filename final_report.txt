2. andrewyng/aisuite:
   star: 15255  语言/技术: Python, OpenAI, Anthropic, Google, Ollama, MCP (Model Context Protocol), Streaming, Async
   项目简介: aisuite 是一个轻量级 Python 库，提供统一的 Chat Completions API 和 Agents API，让开发者可以轻松切换多个 LLM 提供商（如 OpenAI、Anthropic、Google、Ollama 等）并构建智能体应用。它同时驱动了桌面 AI 助手 OpenWorker，能够在本地执行文件操作、连接 Slack/邮件、生成文档等任务。一句话：打工人神器，统一多模型调用，还能做桌面自动化。
   亮点: 统一的 Chat Completions API：只需改变模型名字符串即可在多个 LLM 提供商间切换，降低集成成本。; Agents API + Toolkits：简单传个 Python 函数就能让模型调用工具，还内置文件、Git、Shell 等工具包，支持 MCP 协议。; 驱动 OpenWorker 桌面应用：一个独立的 AI 同事，能读取文件、连接 Slack/邮件、生成文档和电子表格，支持本地模型，数据不出机器。
   详细报告: aisuite 是一个轻量级 Python 库，由 Andrew Ng 团队开发，旨在简化多 LLM 的集成和智能体构建。它分为两层：底层是统一的 Chat Completions API，上层是 Agents API 及工具系统。

- **Chat Completions API**：提供与 OpenAI 兼容的接口，支持 temperature、max_tokens、tools 等标准参数。模型命名格式为 `<provider>:<model-name>`，库自动路由到对应提供商。支持流式输出（同步和异步），工具调用也支持流式。目前支持的提供商包括 OpenAI、Anthropic、Google、Mistral、Hugging Face、AWS、Cohere、Ollama、OpenRouter、Requesty 等，几乎覆盖主流。
- **Agents API**：允许将普通 Python 函数作为工具传给模型，库自动生成 JSON schema 并处理多轮调用。通过 `max_turns` 参数可控制最大工具调用轮数。此外提供更高级的 Agent 类和 Runner：Agent 可以配置模型、指令和工具包；Runner 负责执行并返回结果。内置工具包包括 `files`（文件操作）、`git`（Git 操作）、`shell`（Shell 命令），以及通过 MCP 协议接入任意 MCP 服务器。工具策略（如审批策略）、状态存储（内存/文件/Postgres）和工件/追踪功能，让生产部署更可靠。
- **OpenWorker**：基于 aisuite 构建的桌面应用，提供图形界面，支持聊天、深度研究、自动执行任务（如读写文件、连接 Slack/邮件、生成 PDF/文档/表格、定时自动化）。用户可自带 API Key 或使用本地 Ollama 模型，数据保留在本地。

技术实现上，aisuite 使用 Python，通过适配器模式支持新提供商。安装简单，可选安装对应提供商的 SDK。整体设计清晰，文档完善，含有快速开始和多个示例。

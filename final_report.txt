6. **管理后台**：Web UI 提供模型下载（HuggingFace）、实时监控、聊天、基准测试和每模型设置，支持多语言（中、英、日、韩等），所有 CDN 依赖内嵌，可完全离线使用。

7. **多 Mac 分布式推理（实验性）**：支持通过 MLX pipeline ranks 将模型拆分到不同内存大小的 Mac 上，使用 Ring 或 Thunderbolt RDMA/JACCL 通信，提供实时分片/性能地图。

技术栈方面，后端使用 Python + FastAPI 作为 API 框架，模型推理基于 Apple 的 MLX 框架和 mlx-lm、mlx-vlm，自定义内核使用 Metal 编写以加速特定模型（如 GLM-5.2），缓存存储使用 safetensors。桌面端使用 Swift/SwiftUI，打包使用 venvstacks 实现可移植 Python 环境。项目还集成了 MCP（Model Context Protocol）支持。

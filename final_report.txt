   详细报告: oh-my-hermes（简称 OMH）做的事情，用一句话说就是：给 Hermes Agent 穿上一身"职业装"。Hermes 本身是 Nous Research 出的自然语言 Agent 入口，而 OMH 声明自己"永不替换 Hermes，也不在它背后藏一个编码执行器"，只做 Hermes 原生技能之上的操作层——由它来框定问题、挑选工作流和证据门禁，然后把原生技能当作"能力"塞进这条受治理的路径里运行。安装极其轻量：macOS/Linux 一条 curl | sh，Windows 一条 irm | iex，也支持 Homebrew、Bun、npm 全局安装，甚至可以直接把一段带 commit SHA 固定协议的提示词粘给 AI Agent 让它自己装（要求先 git ls-remote 解析出完整 SHA，不许用 main 顶替，并保留你原有的 Hermes 配置）。之后必须跑 omh setup 做交互式模型链访谈，omh update 升级，omh doctor 体检，omh model 用方向键按工作类别挑模型和 effort（同一个选择器在 Hermes TUI 里是 /omh-model）。

它对外交付的能力可以归成三大块。第一块是编码智能（README 中的 01–04、07）：请求先被评分再分发，改个变量名走 quick 快车道，"找出 X 的所有引用"会触发穷尽搜索信号被送到不会漏一个的模型上；12 条 category 链由用户在一个 JSON 文件里读写覆盖，链在 provider 拒绝模型时自动前进，而如果某次分发会继承一个根本服务不了该模型的 provider，系统会直接拒绝而不是悄悄降级；提示词按 13 个模型家族逐一家族校准（Claude 被告知清单已完成、Gemini 被告知没有工具输出就不算证据、Qwen3-Coder 永不输出 thinking 标签、DeepSeek 的版本和思考模式是契约字段），并且校准块是"测过再留"的。并行侧，ulw-work 把计划切成永不共享文件的单元，每个单元从同一个 pinned SHA 开 worktree，一轮内发多个工具调用，回传四种状态的结构化结果。第二块是长期记忆（08）：所有记忆都走审查卡流程，带来源、带复查日期，沉默会让它逐级老化，下个会话拿到的是按任务排序、按 token 预算裁剪、冲突和重复已消解的 recall pack，命中时 Hermes 会在所有它发声的界面上打上 🧠 OMH — recalled 2 memories。第三块是工作流包（05–06）：OMH dock 在提示符下方一行行展示每个 lane 的模型、effort、轮次、token、成本，phase todo 在提示符上方显示这次运行自己的编号阶段清单（不是事后总结）。

4. SnailSploit/Claude-Red:
   star: 3695  语言/技术: Markdown (SKILL.md 结构化技能文档), Claude Skills 系统 / Claude Code / Claude.ai, Bash (install.sh 安装脚本与 git sparse-checkout 用法), Git (sparse-checkout / blob:none 稀疏克隆)
   项目简介: 一句话概括：这是给 Claude 装上的『红队技能包』——作者把渗透测试、漏洞挖掘、红队作战的方法论拆成一份份结构化的 SKILL.md 文件，丢进 Claude Skills 系统后，Claude 就从『只会说正确的废话的聊天机器人』变成『懂工具的上下文感知红队操作员』。它的核心痛点在于：通用大模型虽然什么都知道一点，但干安全活儿时往往缺少体系化流程、工具链细节和边界情况（edge case）的处理经验；而这个项目把 SQL 注入、XSS、SSRF、SSTI、JWT、ADCS、WPA3、EDR 免杀、容器逃逸、CI/CD 投毒、社工钓鱼等攻防面，逐个封装成可被对话关键词按需触发的技能文档，用哪个加载哪个，不浪费上下文。

   详细报告: 先给这个项目一个接地气的定位：它不是一段能跑起来的程序代码，而是一套『写给 AI 看的作战手册』。仓库里躺着一堆 SKILL.md 文件，每个文件针对一类攻击面，把方法论、工具链、坑点、以及从低危到拿到 shell 的升级路径整理成结构化的说明。作者称之为 offensive security skills for Claude，也就是让 Claude 在安全场景下表现得像个领域专家，而不是一个含糊其辞的搜索框。

痛点是什么？通用大模型在安全话题上往往『懂概念、缺章法』：它知道 SQL 注入是什么，但未必会系统地带你走完指纹识别→报错注入→盲注→带外(OOB)→绕 WAF 这一整套流程；它知道 Kerberoasting，但未必清楚 ADCS 的 ESC1 到 ESC15 分别踩什么配置。该项目的解法是『知识外挂』：把资深从业者的方法论固化进 SKILL.md，相当于给 Claude 挂载了一颗颗专用大脑。

工作机制上，Claude Skills 系统的特点是按需加载——技能靠对话触发词匹配，你提到的技术方向决定加载哪份文档。这带来的好处是上下文成本可控：不用把上百个技能的全文塞进系统提示，聊到什么才加载什么，省钱又省 token。安装方式也照顾到了不同用户：仓库推荐直接 clone 到 ~/.claude/skills/claude-red 让 Claude 自动加载；也支持用 git sparse-checkout 只拉取某个类别（比如只装 web + active-directory）；在 Claude Code 里可以用 cat SKILL.md | claude --system-file - 把技能当系统提示文档喂进去；在 Claude.ai 网页版则手动粘贴到 Project 的系统提示或对话开头；还贴心提供了交互式 install.sh，支持 --target 指定目录、--category 指定单类别。

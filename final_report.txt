仓库还提供了与 Claude Code 的深度集成方式：用户可以通过插件市场命令 `/plugin marketplace add anthropics/skills` 添加该仓库，然后安装 `document-skills` 或 `example-skills` 插件，之后便可以直接在对话中要求 Claude Code 使用特定技能，例如“用 PDF 技能提取某个文件中的表单字段”。这些技能在 Claude.ai 中已对付费用户可用，也可以通过 Claude API 上传自定义技能。

免责声明部分提醒用户：这些技能主要用于演示和教育，实际使用效果可能与示例有差异，在关键任务中必须自行测试。合作伙伴方面，Notion 等公司也推出了类似的技能集。

- Claude Code 插件系统（用于命令行集成）
- 文件格式处理库（如 docx、xlsx 等，具体实现未在 README 中详述，但可以推测试涉及 Python/JavaScript 库）

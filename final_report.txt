不过，这个仓库已经明确标记为“deprecated”（弃用）。原因是 OpenAI 将技能和插件体系整合到了新的 OpenAI Plugins 仓库中，并推出了更正式的 Agent Skills 开放标准（agentskills.io）。所以对于新用户，文档建议直接前往新仓库或遵循官方构建指南，不要再以本仓库为基础做二次开发。对于想要了解 Agent Skills 早期设计和演进历史的开发者，这个仓库仍有一定参考价值，但不适合生产环境。

   详细报告: Code-Graph-RAG 是一个把代码库变成可交互知识图谱的AI工具，核心思路是：先用 Tree-sitter 这个多语言解析器把各种语言的代码拆成抽象语法树（AST），然后提取出函数、类、方法、模块以及它们之间的调用和引用关系，存进 Memgraph 这个图数据库里。这样一来，整个代码库就变成了一张包含节点和边的知识图谱，节点是代码单元，边是依赖关系。

接着，它用 RAG（检索增强生成）技术，让用户用自然语言提问，比如'这个项目的用户登录流程是怎样的？'，系统会自动把问题翻译成 Cypher 查询（图数据库的查询语言），在图上检索相关代码，再交给AI模型组织成带上下文的回答。

更厉害的是，它还能动代码：通过 AST 级别的精准 patch 来修改函数实现，改之前会预览 diff，避免直接改文本破坏语法。它还集成了 ast-grep，支持按 AST 模式做结构搜索和替换，比如'找出所有没加错误处理的 HTTP 请求调用'，这种操作比正则表达式要准确得多。

另外，它内置了死代码检测，通过从程序入口点（如 main 函数）沿着调用边和引用边遍历，找出哪些函数和模块是永远走不到的。

支持的语言非常广：Python、TypeScript、TSX、JavaScript、Rust、Go、Java、C、C++、C#、PHP、Lua、Dart 都完全支持，Scala 在开发中，Ruby 也有基于 ast-grep 的结构支持（能识别模块、函数、类）。这意味着一个混合语言的大仓库也能统一建图，跨语言分析不再是梦。

项目提供了完整的 CLI 工具和 Python SDK，还支持 MCP（Model Context Protocol）服务器，这意味着 Claude Code 等AI编程助手可以直接接入它来查询和修改代码。安装方面，它发布在 PyPI 上，但需要 Docker 跑 Memgraph 数据库，还有 cmake 和 ripgrep 依赖。

文档非常全面，覆盖安装、快速开始、配置、CLI参考、交互式查询、代码优化、死代码检测、图导出、实时更新、MCP服务器、架构设计、语言支持矩阵、数据流边、Python SDK等等，对二次开发相当友好。

一、它到底怎么运作。框架把复杂的交易决策拆成专业化角色。第一层是 Analyst Team（分析师团队），包含四位“打工人”：Fundamentals Analyst 看公司财报和业绩指标，判断内在价值并挑财务红旗；Sentiment Analyst 把新闻标题、StockTwits、Reddit 的讨论聚合成一个情绪读数，用来看短期市场情绪；News Analyst 盯全球新闻和宏观指标，判断事件对市场的影响；Technical Analyst 用 MACD、RSI 这类技术指标找形态、预测价格走势。第二层是 Researcher Team（研究员团队），由看多和看空两派组成，他们对分析师团队的结论做批判性审视，通过结构化辩论来回权衡潜在收益与内在风险——相当于公司内部的“多空吵架环节”。第三层是 Trader Agent（交易员），把分析师和研究员的报告汇编成交易决策，决定下单的时机与规模。第四层是 Risk Management（风控团队）与 Portfolio Manager（组合经理），风控持续评估市场波动率、流动性等风险因子并给出评估报告，组合经理据此批准或否决交易提案，批准后订单送到模拟交易所执行。

二、技术实现。整个流程用 LangGraph 搭建，官方称这样能保证灵活性和模块化——本质上是一个带状态的有向图编排，每个 agent 是节点，辩论轮次、LLM 选择等都是可配置项。配置通过 DEFAULT_CONFIG.copy() 修改，核心字段包括 llm_provider、deep_think_llm（复杂推理用的大模型）、quick_think_llm（快速任务用的轻量模型）、max_debate_rounds（辩论轮数）等。使用上可以直接 Python 调用：初始化 TradingAgentsGraph，然后 ta.propagate("NVDA", "2026-01-15") 返回一个 decision；也可以跑 CLI 或 Docker（docker compose run --rm tradingagents），本地模型走 docker compose --profile ollama。

三、数据与市场覆盖。行情侧依赖 Yahoo Finance，用带交易所后缀的 ticker 标识市场：美股 AAPL/SPY、港股 0700.HK、东京 7203.T、伦敦 AZN.L、印度 RELIANCE.NS/.BO、加拿大 .TO、澳洲 .AX、A 股 600519.SS/.SZ、加密 BTC-USD 等，官方称公司身份与 alpha 基准会自动按市场解析。另外版本日志里提到了 Alpha Vantage、FRED 宏观数据、Polymarket 等数据供应商。

四、持久化与恢复，这是我认为最实用的工程亮点。第一是 decision log（决策日志），默认常开，每次跑完把决策追加到 ~/.tradingagents/memory/trading_memory.md；下次跑同一 ticker 时会抓取已实现收益（raw 与相对 SPY 的 alpha），生成一段反思，并把最近同 ticker 决策加上跨 ticker 的经验教训注入组合经理的提示词。路径可用 TRADINGAGENTS_MEMORY_LOG_PATH 覆盖。第二是 checkpoint resume，需要 --checkpoint 显式开启，LangGraph 每个节点后保存状态，崩溃/中断后可从上一步继续，日志里会打印 Resuming from step N 或 Starting fresh；每个 ticker 一个 SQLite 库，位于 ~/.tradingagents/cache/checkpoints/<TICKER>.db，可用 --clear-checkpoints 重置。

五、关于“可复现性”，官方写得很坦诚，也值得开发者认真读：两点跑同一 ticker 同一日期结果可能不同，这不是 bug 而是特性。原因包括：语言模型采样本身非确定性（即使固定 temperature，供应商也不保证逐字节一致，而推理模型因为内部推理过程也是采样的，波动最大）；以及实时数据会变——新闻、StockTwits、Reddit 随时间返回不同内容，所以今天跑和上周跑即使交易日期相同，输入也不同。降低波动的办法是调低 temperature（config 里的 temperature 或 .env 中的 TRADINGAGENTS_TEMPERATURE），但当前策展的模型多为 reasoning-first，基本忽略 temperature，想要更稳定就得显式指定非推理模型。官方也明确说回测结果不保证与任何已发表数字一致，应当把它当作研究多智能体分析的研究脚手架，而不是一个收益固定的策略。

六、文档里明确“不再随机”的部分：被分析的公司主体在任何 agent 运行前由 ticker 确定性解析；市场分析师对精确价格和指标的说法锚定在验证过的数据快照上。这说明团队确实在处理 LLM 投研最常见的两类翻车：张冠李戴和编造价格。

认证与理论纵深：README 宣称本项目覆盖了若干奠基论文作为课程骨架，包括 Attention Is All You Need（Phase 7）、GPT-3（Phase 10）、DDPM（Phase 8）、InstructGPT/RLHF 与 DPO（Phase 10）、Chain-of-Thought Prompting（Phase 11）、ReAct（Phase 14）、Anthropic 的 Model Context Protocol（Phase 13）。Claude Certification Academy 则是一个免费开源的备考项目，覆盖四条官方认证轨道（Associate Foundations、Developer Foundations、Architect Foundations、Architect Professional），每条轨道由蓝图对齐的课程、可运行 Lab、诊断题、Capstone 和一份全长度原创模考组成，并支持用 claude-certification 技能在 Claude Code / Codex / ChatGPT / Cursor 等宿主里选择轨道、生成持久化的 CLAUDE-CERTIFICATION.md 路线、逐步教学并给出基于产物的反馈。

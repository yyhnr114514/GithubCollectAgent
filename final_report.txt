3. RyanCodrai/turbovec:
   star: 14314  语言/技术: Rust, Python, SIMD (NEON, AVX-512), TurboQuant, Lloyd-Max 量化, Maturin, LangChain, LlamaIndex, Haystack, Agno
   项目简介: turbovec 是一个基于 Rust 的高性能向量索引库，提供 Python 绑定。它采用 Google Research 的 TurboQuant 算法，实现极致的内存压缩（如 1000 万向量从 31GB 压缩到 4GB），同时保持甚至超越 FAISS 的搜索速度。核心创新在于数据无关的量化器，无需训练阶段，支持在线增量添加、SIMD 加速搜索（ARM NEON 和 x86 AVX-512）、以及搜索时过滤。适合构建隐私敏感、内存受限或低延迟的 RAG 系统。
   亮点: 原子级内存压缩：1000 万 1536 维向量从 31GB (float32) 降到 4GB (2-bit)，压缩比 16x。; 无需训练：数据无关的 TurboQuant 量化器，无训练阶段，支持在线增量添加，无需重建索引。; SIMD 加速搜索：手写 NEON 和 AVX-512BW 内核，速度超越 FAISS FastScan 最多 19%（ARM）或持平（x86）。; 搜索时过滤：支持白名单 ID 或位掩码过滤，过滤逻辑直接在 SIMD 内核中短路，高性能。; 完整生态集成：提供 LangChain、LlamaIndex、Haystack、Agno 等框架的即插即用替换组件。; 长度重归一化评分：校正量化产生的内积估计偏差，提升召回率。
   详细报告: turbovec 是一个开源的向量索引库，核心算法源自 ICLR 2026 论文《TurboQuant》。它解决的是传统向量检索中内存占用大、需要预训练、搜索速度慢的问题。技术实现上，turbovec 将每个向量先归一化为单位方向，然后应用随机旋转，使得各坐标独立服从已知的 Beta 分布（高维下趋近高斯）。接着利用 Lloyd-Max 算法预计算最优量化桶（2-bit 对应 4 桶，4-bit 对应 16 桶），这个码本是基于数学分布而非数据，因此无需训练。每个坐标被量化成小整数后紧密位打包，实现 16 倍压缩（1536 维向量从 6KB 降到 384 字节）。为了弥补量化带来的内积偏差，turbovec 在编码时额外存储一个长度重归一化标量，在搜索时乘回，使评分无偏。搜索时，查询向量经同样旋转后，直接对码本进行查找表评分，SIMD 内核（NEON/AVX-512）实现高速并行。支持在线添加向量（add）、删除（remove，IdMapIndex 支持 O(1) 删除）、持久化（write/load）。此外，turbovec 提供了与 LangChain、LlamaIndex、Haystack、Agno 等主流 RAG 框架的集成，只需替换导入即可使用。性能基准显示，在 ARM M3 Max 上，turbovec 比 FAISS FastScan 快 10-19%；在 x86 Sapphire Rapids 上，4-bit 配置领先约 5%，2-bit 略逊（受限于 AVX-512 VBMI 路径）。召回率方面，在 OpenAI 1536/3072 维数据集上，turbovec 与 FAISS PQ 相当或略优，尤其在低比特率下表现更好。

   star: 15255  语言/技术: Python, OpenAI, Anthropic, Google, Ollama, MCP (Model Context Protocol), Streaming, Async
   项目简介: aisuite 是一个轻量级 Python 库，提供统一的 Chat Completions API 和 Agents API，让开发者可以轻松切换多个 LLM 提供商（如 OpenAI、Anthropic、Google、Ollama 等）并构建智能体应用。它同时驱动了桌面 AI 助手 OpenWorker，能够在本地执行文件操作、连接 Slack/邮件、生成文档等任务。一句话：打工人神器，统一多模型调用，还能做桌面自动化。
   亮点: 统一的 Chat Completions API：只需改变模型名字符串即可在多个 LLM 提供商间切换，降低集成成本。; Agents API + Toolkits：简单传个 Python 函数就能让模型调用工具，还内置文件、Git、Shell 等工具包，支持 MCP 协议。; 驱动 OpenWorker 桌面应用：一个独立的 AI 同事，能读取文件、连接 Slack/邮件、生成文档和电子表格，支持本地模型，数据不出机器。
   详细报告: aisuite 是一个轻量级 Python 库，由 Andrew Ng 团队开发，旨在简化多 LLM 的集成和智能体构建。它分为两层：底层是统一的 Chat Completions API，上层是 Agents API 及工具系统。

- **Chat Completions API**：提供与 OpenAI 兼容的接口，支持 temperature、max_tokens、tools 等标准参数。模型命名格式为 `<provider>:<model-name>`，库自动路由到对应提供商。支持流式输出（同步和异步），工具调用也支持流式。目前支持的提供商包括 OpenAI、Anthropic、Google、Mistral、Hugging Face、AWS、Cohere、Ollama、OpenRouter、Requesty 等，几乎覆盖主流。
- **Agents API**：允许将普通 Python 函数作为工具传给模型，库自动生成 JSON schema 并处理多轮调用。通过 `max_turns` 参数可控制最大工具调用轮数。此外提供更高级的 Agent 类和 Runner：Agent 可以配置模型、指令和工具包；Runner 负责执行并返回结果。内置工具包包括 `files`（文件操作）、`git`（Git 操作）、`shell`（Shell 命令），以及通过 MCP 协议接入任意 MCP 服务器。工具策略（如审批策略）、状态存储（内存/文件/Postgres）和工件/追踪功能，让生产部署更可靠。
- **OpenWorker**：基于 aisuite 构建的桌面应用，提供图形界面，支持聊天、深度研究、自动执行任务（如读写文件、连接 Slack/邮件、生成 PDF/文档/表格、定时自动化）。用户可自带 API Key 或使用本地 Ollama 模型，数据保留在本地。

技术实现上，aisuite 使用 Python，通过适配器模式支持新提供商。安装简单，可选安装对应提供商的 SDK。整体设计清晰，文档完善，含有快速开始和多个示例。

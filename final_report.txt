   详细报告: User Scanner 是一个专为安全研究人员、渗透测试人员和网络调查员设计的 OSINT 工具，它解决的核心痛点是：在多个平台分散地查找一个人的数字足迹既耗时又低效。这个项目把 465+ 个网站的检测逻辑统一封装，用户只需一条命令，就能同时探测目标邮箱或用户名在哪些平台注册过，并提取公开的附加信息（如头像、简介、关注者数、用户 ID、卖家状态等）。

它的核心逻辑基于 Python 的异步并发模型，利用 httpx 提供高性能 HTTP 请求，再通过 curl_cffi 模拟真实的 TLS 指纹，让请求看起来像是来自普通浏览器，从而绕过一些简单的反爬机制。这种并发扫描和指纹伪装技术，使得它能在几秒钟内完成对数百个平台的探测，而不是像传统脚本那样逐个等待。

交叉扫描与枢轴引擎是它最亮眼的创新点之一。传统 OSINT 工具通常只能单向查询，而这个工具可以从一次扫描的返回结果中自动提取新线索。比如你先扫描一个邮箱，发现它在某个论坛注册了，然后从那个论坛的公开页面里挖出用户名和更多链接，再自动去扫描这些新线索，形成一张不断扩大的情报网。这种递归式的信息挖掘，极大地提升了调查的深度和广度。

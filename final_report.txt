   详细报告: OpenViking 是一个开源上下文数据库，专为 AI Agent 设计。它的核心创新在于把 Agent 的记忆、资源和技能抽象成一个虚拟文件系统，通过 viking:// URI 进行统一访问。以往 Agent 的上下文通常依赖黑盒向量数据库，难以追踪和精细控制；而 OpenViking 让 Agent 像操作文件一样浏览上下文，确定性更强。

在存储层面，每条内容被划分为三层：L0（摘要）、L1（概览）和 L2（详细信息）。写入时自动生成 L0/L1，检索时只加载任务所需的深度，从而大幅节省 token。例如在 LoCoMo 基准上，接入 OpenViking 后输入 token 可降低 34.3% 到 91%，查询延迟降低 58% 到 66%，同时记忆准确率从原生记忆的 24-57% 提升到 80-83%。

检索方面，OpenViking 采用目录递归检索：先用向量搜索定位最相关的目录，再逐层下钻，保证结果带有上下文。每次检索的“浏览轨迹”都会被记录，一旦结果异常，可以清晰看到是哪个路径导致，方便调试。

此外，会话提交后，系统会异步抽取用户偏好和 Agent 经验，转化为长期记忆。例如在 tau2-bench 中，经验记忆使零售任务成功率提升 6.87 个百分点，航空任务提升 11.87 个百分点。

项目提供 Python CLI（openviking-server）和 ov 客户端命令，支持 Volcengine、OpenAI、Codex、Kimi、GLM、Ollama 等多种模型提供商。同时原生集成 Claude Code、Codex、Cursor、LangChain 等主流 Agent 框架，也支持 MCP 协议。OpenViking Helper 桌面控制台（beta）提供可视化配置和会话追踪。

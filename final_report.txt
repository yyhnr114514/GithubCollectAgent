   详细报告: OpenMontage 是一个革命性的开源项目，它重新定义了视频制作的方式。核心思想是：让你喜欢的 AI 编程助手（如 Claude Code、Cursor、Copilot、Windsurf、Codex）变成一个全自动的视频制作工作室。你只需要用自然语言描述你想要什么，例如“做一个 60 秒的动画解释器，讲神经网络如何学习”，代理就会自动完成以下工作：网络搜索研究主题、生成 AI 图像、撰写脚本、进行有情感表达的配音、寻找免版税背景音乐、生成单词级字幕，并最终渲染成完成的视频。

最令人印象深刻的是它不仅仅局限于将静态图片变成幻灯片式视频。它支持真正的“视频视频”——代理从免费素材库（例如 Archive.org、NASA、Wikimedia Commons）构建一个可搜索的语料库，通过 CLIP 检索真实的运动剪辑，将它们编辑到时间轴上，并合成最终作品。这意味着你可以制作基于真实素材的纪录片、新闻蒙太奇等，而不需要昂贵的付费素材。

项目架构是高度模块化和代理驱动的。所有工作流都通过 YAML 清单（pipeline_defs/）定义，舞台导演技能位于 skills/pipelines/，工具通过注册表自动发现。代理首先选择正确的流水线，然后读取清单和技能，再使用工具执行。工具注册表允许动态扩展，新增工具只需继承 BaseTool 并实现接口，即可被自动发现。

Backlot 是一个独特的可视化看板系统，它将生产过程的“幕后”实时展示出来：阶段灯亮起、脚本变成剧本页面、场景卡片在生成时闪烁，每个提供商决策和花费都一览无余。更重要的是，它成为了真实的审批关卡：资源生成会暂停在逐场景的联系表上，显示镜头、提示词、单个资产成本和质量评分，让你在渲染之前批准视觉素材。这一功能对于需要创意控制的专业人士来说极其有价值。

在代码层面，OpenMontage 结合了 Python（核心工具和多代理协调）、Node.js/React（Remotion 合成引擎）、以及 HTML/GSAP（HyperFrames 渲染器）。它内置了多种渲染后端：Remotion 适合数据驱动的解说视频和现有 React 场景堆栈；HyperFrames 则适合书法排版、产品宣传、动态图形密集型的项目，甚至支持 SVG 角色动画。

预算控制是另一个亮点：代理在执行前估算成本，支持预留资金、记录实际花费，并提供 observe/warn/cap 三种模式，可配置单次操作审批阈值和总预算上限。所有提供商选择都会通过 7 个维度的评分，并保留可审计的决策日志，让你完全理解为什么最终输出看起来是这个样子。

此外，项目可以在零 API Key 的情况下运行：Piper TTS 提供免费离线文本转语音，Archive.org、NASA、Pexels 等提供免费素材，Remotion / HyperFrames 负责渲染。对于有 GPU 的用户，还可以通过 make install-gpu 启用本地视频生成模型（如 Wan2.2、Hunyuan），彻底摆脱云服务依赖。
